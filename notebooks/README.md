# Notebook

`preprocessing.ipynb` dùng để khám phá dữ liệu và kiểm tra chất lượng preprocessing. Có thể mở từ root hoặc thư mục `notebooks/`; cell cấu hình tìm root repository và dùng chung `ragqa.paths`.

Cài môi trường notebook theo `requirements/notebook.txt`. Các cell và kết quả lưu sẵn được giữ lại; lần sắp xếp chỉ cập nhật đường dẫn, không chạy lại kiểm định hoặc thay kết quả nghiên cứu.
